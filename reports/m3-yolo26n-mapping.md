# M3 官方 YOLO26n 两级存储与冻结 RTL 验证

320×320 发布模型保留 YHB1 与 `z15-mmio-abi-v1`，SHA-256 为
`c7cbdaf377df7c837d80291a668f8b3eec3983c1094f600e227eaaca4760a1bf`。
输入是 320×320 NHWC RGB 有符号 INT8，加一个值为 0 的通道。输出由三组
检测头的边框与分类张量、定点缩放量及概率查找表组成。

| 320×320 静态资源 | 字节 |
| --- | ---: |
| DDR 权重与常量 | 2,577,440 |
| DDR 帧区 | 409,600 |
| DDR 激活复用区 | 1,433,600 |
| DDR 地址峰值 | 4,420,640 |
| SRAM 并发峰值 | 1,461,376 |
| Half-0 独立峰值 | 1,002,368 |
| Half-1 独立峰值 | 549,120 |
| 每帧 DMA | 31,128,928 |

DDR 溢出区按张量活跃期复用。YHB1 的 INITIAL 段只携带常量与必要的静态填充。
编译器检查每次读取都由常量、运行时输入或已通过 DMA fence 的先前写回覆盖。
双半区交替发射，单次 DMA 的地址、长度和 scratch 所有权均由旧版 C99 加载器复核。

245 个量化图节点在 PL 上执行，展开为 NPU 398、VPU 348、GPU 1,082 次发射。
其余 35 个量化图节点对应终端坐标计算、Sigmoid 分数查表、两级 TopK 与索引，在 PS
侧的 C99 代码中合并执行。原始 384 个 ONNX 节点的逐项归属见
[m3-yolo26n-operator-placement.csv](m3-yolo26n-operator-placement.csv)。按原始逻辑运算量估计，PL 占 99.26%，口径为每 MAC
计两次标量运算、TopK 计保守上界。部署性能使用 RTL 实测周期。

102 层 Conv 和 4 层 MatMul 的主乘加使用 NPU DOT4。K 超过 511 时以
VPU 分通道、NPU 产出 INT32 部分和、GPU 宽位累加和 requant 取代单条描述符。
8 层深度卷积用按 16 通道分组的块对角权重。VPU 完成原生张量重排、池化、逐元素操作、
查表和部分融合，GPU 还执行精细 Q23 Softmax。可编译原生 VPU Softmax 对照，
保持已选权重和偏置时高置信度类别一致率为 12/14、平均 IoU 0.9328。
发布模型使用精度更高的 Q23，类别一致率 13/14、平均 IoU 0.9601。

独立 C99 定点 HAL 读取并执行发布 YHB1，在 4 张真图上每张 176,400 B 原始检测头逐字节
一致，末端 C99 解码的每张 300 条 Q16.16 坐标、Q16.16 置信度和 INT64 类别共
8,400 B 逐字节一致。128×128 同拓扑已通过整帧 Step 2 RTL，比对六个检测头共 28,224 B。
320 代表层覆盖首层空间分块、s2、1×1、深 K、Depthwise、C3k2 残差、SPPF、上采样、
Concat/Split、Attention 两次 MatMul 与两种 Softmax、三个尺度检测头。

## 320×320 板载时钟比冻结回放

GPU:NPU=4:5，Z15 冻结提交 4d410d7。C99 直接加载发布 YHB，bus.jpg 的
六个 INT8 输出逐字节通过。按 MMIO 读写拒绝路径和最终寄存器，SLVERR、ERROR、
非法 DMA 均为 0。时钟折算采用 NPU 域拍数，并保留仪表读取开销。

| 计数 | 拍 |
| --- | ---: |
| NPU | 3,670,629 |
| VPU | 5,532,639 |
| GPU | 42,106,200 |
| DMA | 1,333,077 |
| NPU/VPU↔GPU 重叠 | 0 |
| 计算↔DMA 重叠 | 487,918 |
| 整帧 | 53,743,506 |

125 MHz 折算 429.948 ms／帧、2.326 FPS。
164.555 MHz 等比例折算 326.599 ms／帧、3.062 FPS。
这里只换算 RTL 计数，板端应用需另外计入 Linux UIO、摄像头与 PS 解码。
