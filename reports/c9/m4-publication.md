# C9 出版交付与回归

论文图件使用 7.16 英寸双栏宽度，四张图分别导出 PDF、可编辑 SVG 和 600 dpi PNG。LaTeX 表格在 IEEEtran conference 中编译，无 Overfull 报告。校验了实际 PNG 像素和 DPI、SVG 文本节点和 PDF 格式，并检查四张图的渲染外观。启用对数刻度的图面使用正值门禁。静态工具的 TIFF 提示超出本次 PNG 交付格式。

C1–C9 软件单测通过。历史核心回归按照冻结硬件和旧公开头文件重新执行。旧 O4 13/13、Z15 YHB 15/15、CRC 30/30、非法 DMA 20/20 均通过，C6–C8 旧包 C99 四图数据合计 16/16。x86-64 与 AArch64 严格 C99 重新构建通过，AArch64 CLI 的唯一动态依赖为 libc.so.6。

公开 C99 头文件、旧部署案例与冻结 RTL 保持兼容。C9 只使用 Verilator 与包内软件工具。四项图、两张 IEEE booktabs 表、双语图注与中文报告在主交付目录。核验口径与原始路径可从统一账本和归档日志追溯。
