# Valence（蔚澜）Phase 17 编译器候选

C14-v2 从冻结 Phase 17 5545b9d1f4e70c25a7e15d8f9d863ac012096e85 获取 RTL。编译器的显式目标为 p17，公开 Step 2 YHB1 入口继续使用原来的格式。

## YOLO26n

大 K 卷积在每个 1 MiB 半区独立装载输入、权重和可选零边界。空间宽度超过 16 时，VC COPY 用原始全局坐标构造包含 halo 的连续条带。TC 以 M≤16、N≤16 运行，迟写续接 K 块，完成后才做逐通道 requant 和 LUT。VC 合并 OC 面板并散布条带。512 输入通道的 1×1 节点用 VC SPLIT 生成 K=508 与 K=4 的紧凑 GEMM 输入，避开隐式卷积形状字段的 9 位上限。

复用 C7 的量化元数据和 C8 的编译选项。通过 tools/compile_c6_yolo.py 的 --target p17 和 --bus-vectors 参数生成独立仿真流。tools/c14_replay_reference.py 可用编译出的 C99 功能 HAL 对六个检测头做逐字节比较。

## Qwen2.5

原模型 YSQC12 和 KV8 契约继续使用原来的权重和秩序。tools/c14_block16.py 可把 Gate 和 Up 的 48 个 W4 张量重排成 P17 实验布局。QKV、O、Down、词表和 KV8 保持原格式。GPU 保留 RoPE 与残差，Host 保留 Q16 非线性。

每个 16 输出通道面板按 G64 或 G128 将权重保持为有符号 W4。偶数 K 放在低 nibble，奇数放在高 nibble。共享尺度以 Q24 保存，在每 token 上结合动态 A8 尺度并计算一个公共定点单位，从而生成每组的 Q0.8 系数。续接路径在每个点积缩放后做最近偶数舍入，最后一个块才排出 16 个 INT32。投影完成后统一恢复 Q16 单位和逻辑通道次序。

S1 在相邻通道中搜索共享尺度。S2 额外迁移行尺度并聚类通道。S3 增加第二个 W4 残差面，权重单位为主面的 1/16。S3-H2 对第 0 和第 23 层保留 C12 精确归并，使用 --protect 0 --protect 23 构建。具备 P17 面板布局的镜像可用显式 --target p17。CPU 参考与设备路径共用系数和恢复逻辑，旧镜像无需重新打包。

## 验证

tools/c14_p17_smoke.sh 只在专属内存盘生成派生源码与 Verilator 构建。Yosys 内嵌路径换算到发布路径后核对派生 RTL 的 SHA-256。编译和回放串行编排，编译最多两个工作任务。主机与 cgroup 的有效可用内存均需达到 6 GiB，低于门槛按 90 秒间隔轮询，等待期限为 180 分钟。
